Feature weights

Ordered by influence

The model is a logistic regression predicting P(donor accepts). A positive weight pushes a donor up the ranking; a negative weight pushes them down.

How it learns

  1. Every invitation records the 14-feature vector used to score that donor.
  2. When the donor accepts or declines, that becomes a labelled example.
  3. Once enough new labels accumulate, weights are refit by gradient descent with L2 regularisation, starting from the expert prior.
  4. The new version is evaluated on a 25% holdout and published only if training succeeds.

Fairness note

The model deliberately uses no demographic attribute beyond what is medically required (blood group, age and weight eligibility). It never sees name, gender, religion or ethnicity, so it cannot rank on them.
